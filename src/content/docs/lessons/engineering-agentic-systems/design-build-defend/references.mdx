## Source material

The capstone introduces no new claims; it consolidates the track. These are the public sources the track's lessons drew on, gathered in one place.

- **[Building Effective AI Agents](https://www.anthropic.com/engineering/building-effective-agents)**, Anthropic engineering blog, December 19, 2024. The essay behind the track's workflow-versus-agent line and its simplicity principle. If you reread one source after finishing the track, make it this one; it reads differently once you have built something.
- **[How we built our multi-agent research system](https://www.anthropic.com/engineering/multi-agent-research-system)**, Anthropic engineering blog. The production account behind lesson 5's orchestration and error-propagation material.
- **[Writing effective tools for agents, with agents](https://www.anthropic.com/engineering/writing-tools-for-agents)**, Anthropic engineering blog. The guidance behind lesson 4's description and error-design standards.
- **[Claude Code documentation](https://code.claude.com/docs/)**, Anthropic. Memory and configuration (lesson 2), MCP configuration (lesson 4), the Agent SDK's subagent pages behind lesson 5, and headless mode with the CLI reference (lesson 7), in current canonical form.
- **[Model Context Protocol](https://modelcontextprotocol.io/)**. The spec and the build-a-server tutorial that scaffold the capstone's custom tool.
- **[Claude Developer Platform documentation](https://docs.anthropic.com/)**, Anthropic. Tool use and structured output, the pages behind lesson 3.
