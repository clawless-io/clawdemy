## What you'll learn

This is lesson 3 of Phase 2, *How models think: the transformer architecture*, in Track 5 (AI Foundations). The full Stanford CME 295 course materials are at [cme295.stanford.edu](https://cme295.stanford.edu/). Phase 2 so far gave you the single-head attention mechanism and its multi-head generalization. This lesson assembles them into a complete transformer block: the repeating unit stacked many times to build a real model. A block is more than attention. It wraps attention with a feed-forward network, residual connections, and layer normalization. This lesson covers each of those pieces, why each one is necessary, and what the original "Attention Is All You Need" architecture diagram actually represents. When you finish, you can read that diagram and name every component, and you have the vocabulary to recognize the variants modern models have built on top of it (RMSNorm, RoPE, grouped-query attention, and so on).

## Where this fits

This is lesson 3 of Phase 2, *How models think: the transformer architecture*. The previous lessons introduced attention and multi-head attention. This lesson combines them into one complete transformer block. The next lesson, *How modern models inject position into attention (RoPE)*, covers how the field moved position encoding from the input embedding into the attention computation itself, the first of three places where modern LLMs genuinely diverge from the 2017 architecture.

## Before you start

**Prerequisites:** the [attention lesson](/lessons/ai-foundations/how-attention-works/lesson/) and [multi-head attention lesson](/lessons/ai-foundations/multi-head-attention/lesson/) are required. This lesson builds directly on the query, key, and value vectors and the split-run-concatenate pattern from those two lessons. The Phase 1 [embeddings lesson](/lessons/ai-foundations/how-words-become-vectors/lesson/) is also useful since position encoding modifies the embedding output before the first block runs.

## By the end, you'll be able to

- Identify the four pieces that wrap around attention to make a complete transformer block (position encoding, feed-forward network, residual connections, layer normalization)
- Explain why attention alone is not enough and what each wrapping piece adds
- Walk through a single forward pass through one block, in order, and trace what changes at each step
- Read the "Attention Is All You Need" architecture diagram and name every component on it
