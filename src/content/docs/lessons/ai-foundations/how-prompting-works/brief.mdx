## What you'll learn

This is lesson 2 of Phase 5, *How we steer models at inference*, in Track 5 (AI Foundations). Modern chat assistants follow instructions because they were post-trained to. The full mechanics of that post-training (supervised fine-tuning, RLHF, and the reward-modeling step) are covered in Phase 4. For this lesson you only need the working assumption that the assistant in front of you wants to follow instructions. This lesson is about how to write the instructions. We'll cover the three prompting patterns that show up everywhere (zero-shot, few-shot, and chain-of-thought), when each one earns its place, when it adds noise, and the structural reason that any instruction-tuned model is vulnerable to prompt injection. Course materials are at [cme295.stanford.edu](https://cme295.stanford.edu/).

## Where this fits

This is lesson 2 of Phase 5, *How we steer models at inference*. The previous lesson ([Token by token: how a transformer generates text](/lessons/ai-foundations/how-text-is-generated/lesson/)) showed how the generation loop works. This lesson covers how to shape what goes into that loop. The next lesson in Phase 6 is *How RAG works: feeding the model what it does not already know*, which builds on prompting by adding retrieval.

## Before you start

**Prerequisites:** the [text generation lesson](/lessons/ai-foundations/how-text-is-generated/lesson/) is required, since prompting is ultimately just choosing the input tokens that condition the next-token prediction loop covered there. If you want to understand why the model follows instructions in the first place (the SFT and RLHF training that produces an instruction-tuned assistant), Phase 4 covers the post-training pipeline; it is not required reading before this one.

## By the end, you'll be able to

- Distinguish zero-shot, few-shot, and chain-of-thought prompting and identify which pattern a given prompt uses
- Explain why few-shot prompting works (in-context learning) and where it stops scaling
- Recognize task types where chain-of-thought helps versus task types where it adds noise without improving accuracy
- Identify a prompt-injection attempt and explain why instruction-tuned models are structurally vulnerable to it
