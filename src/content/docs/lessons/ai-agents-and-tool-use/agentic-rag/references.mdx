## Going deeper on the retrieval black box

This lesson treats retrieval as a black box on purpose. If you want to open it, these are the pieces inside.

- **[Retrieval Augmented Generation for Knowledge-Intensive NLP Tasks (Lewis et al., 2020)](https://arxiv.org/abs/2005.11401)**. The paper that introduced RAG. The primary source for the retrieve-then-generate idea this lesson starts from.
- **[Model Context Protocol](https://modelcontextprotocol.io/)**. An open standard for connecting models to external data sources and retrieval tools, the kind of plumbing a retrieval tool rides on.
