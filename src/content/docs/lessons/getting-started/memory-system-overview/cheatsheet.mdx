## The distinction worth keeping clean

| Layer | What it is | Where it lives | Travels? |
| --- | --- | --- | --- |
| Conversation history | The literal back-and-forth of one chat | Inside that one conversation | No |
| Memory | Distilled facts pulled out of conversations over time | The Memory panel | Yes, across every conversation and every agent |

## The four tiers (most-important to least)

| Tier | What it is | How memories get here | Behavior |
| --- | --- | --- | --- |
| Pinned | Facts you explicitly told [Clawless Computer](https://clawless.ai) to always remember | You Pin them | In every prompt; hard size cap around 2,200 characters total |
| Insights | Classifier inferences confident enough to surface routinely | Classifier auto-extracts (once you turn it on) | Surfaced regularly; promotable to Pinned with a click |
| General | Everything else the classifier noticed but is unsure about | Classifier auto-extracts (once you turn it on) | Included only when relevant to the current message |
| Decayed | Old memories that have aged out of routine use | Auto-aging from disuse | Surfaces only if current context makes them look very relevant again |

## Decayed in one phrase

**Forgetting without deleting.** Memory still exists. Memory still visible in the panel. Memory does not get fed into new conversations unless something current makes it look very relevant. Mimics human forgetting (stop accessing) instead of computer deletion (data gone).

## Three pathways memories get in

| Pathway | What you do | Where the memory lands |
| --- | --- | --- |
| Classifier auto | Turn on Auto-extraction in Settings, Memory (off by default; asks for your consent first), then talk | Insights (high confidence) or General (lower confidence) |
| Ask explicitly | Tell any agent "remember that I prefer..." then confirm the candidate | Wherever Clawless Computer sorts it; you can pin after |
| Add manually | Memory panel, click Add Memory, type the fact, save | In the Memory panel; pin it if load-bearing |

## The Memory panel (where you control what is kept)

| Control | What it does |
| --- | --- |
| Pin or unpin | Move into or out of the Pinned tier |
| Edit | Rewrite the text (useful when the classifier saved something slightly wrong) |
| Delete | Remove permanently |
| Source badge | Shows which conversation the memory was extracted from |
| Last-seen date | Shown for each entry; old dates flag Decayed candidates |
| Search box | Filter across all tiers by keyword |

Open the panel from the Memory icon on the navigation rail on the far left.

## Sharing across agents (the default)

All agents on a single Clawless Computer install share one memory pool. Tell the Assistant your name, the Writer knows it. The Researcher knows it.

Per-agent memory isolation (one agent forgets while another remembers) is on the roadmap. Today, all agents on the install share the same pool.

When you switch agents mid-task, the new agent receives a short briefing of what was happening in the other agent's conversation. Like handing off to a colleague who has not been in the room but gets a one-line summary.

## Privacy in one rule

| Question | Answer |
| --- | --- |
| Where do memories live? | On your computer, in the Clawless Computer data folder. Not on any Clawless Computer server. |
| Where do memories travel? | To the AI provider with each message they are relevant to. |
| The practical rule | If there is a fact you never want leaving your computer, do not save it as a memory. |

Memory is for things that are useful for the agent to know; "useful for the agent to know" means "shared with the AI provider every time it might be relevant."

## Settings worth knowing about

| Setting | Default | What it does |
| --- | --- | --- |
| Auto-extraction on/off | Off | Whether the classifier scans conversations for memory candidates. While off, nothing is sent anywhere for it, and you can still add and pin memories yourself. When on, it sends short excerpts of your conversation to an AI model you choose for it, and it asks for your consent first. |
| Mid-conversation re-injection interval | Every ten messages | How often Insights are re-fed into a long conversation to keep the agent grounded. Lower = grounded but costlier; higher = cheaper but risk of drift. |
| Capacity-pruning notification | See Settings, Memory | Whether to notify you when General memories are pruned. Gives you visibility into what is dropping. |
| Decay rules | Reasonable defaults | How long an unused memory takes to age down toward Decayed. Tighten or loosen if needed. |

Open Settings, gear icon at the bottom of the navigation rail, then Memory section in the sidebar.

## Pitfalls to dodge

- Treating memory and conversation history as the same thing (they are not; history stays inside a chat, memory travels)
- Saving secrets as memories (they travel to the provider with messages; not local-only)
- Cramming everything into Pinned (the cap is intentional; consolidate or unpin)
- Expecting per-agent isolation today (shared pool today; isolation on roadmap)
- Editing a memory and expecting yesterday's replies to update (they were generated with yesterday's state)
- Ignoring the Insights tier once auto-extraction is on (review once early; the inferences may need cleanup or promotion)

## Worth opening once

The **Memory panel**, in the first week. If you turned auto-extraction on, read the Insights tier and clean up one or two that landed slightly off. Either way, pin the one or two facts that should always travel. After that, memory needs little attention.
