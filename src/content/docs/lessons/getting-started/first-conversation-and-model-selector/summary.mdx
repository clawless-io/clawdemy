## The short version

[Clawless Computer](https://clawless.ai) puts a chat in front of you with a model picker close at hand. You type, press Enter, and a reply streams back. The picker, the chip with the current model's name above the message box, lets you choose a model from a curated short list grouped by provider (drawn from the providers you saved a key for, each model labeled with its provider), or type a provider-prefixed name to use an off-list model. You can switch models mid-conversation with no per-conversation lock; the new model continues where the last one left off, and the cost meter follows the model you are using at the moment you send each message. A pick inside a chat changes only that chat; the default for new chats lives in Settings, API Keys. Each agent on the left rail keeps its own conversation history and its own preferred model, so clicking between agents swaps both. The header model name shows the current model you have selected. Once these four pieces (screen areas, picker, switching, per-agent thread) are real to you, the rest of Clawless Computer is additions.

## Core ideas

- Clawless Computer has three screen areas: the **agent rail** on the left (avatars, one per agent, with Assistant as the friendly default), the **chat** in the middle, and the **navigation rail** on the far left (Tools, Skills, Memory, Channels, Cron, Logs, Usage, Settings panels). The chat has four parts: header (agent avatar, conversation title, current model), message area, the **row of controls** above the message box (New conversation, model picker, Skills, Tools, Commands, Feedback), and the message box.
- Sending a message is just typing into the input box and pressing Enter. The activity indicator below your message tells you what the agent is doing in real time. The Stop button replaces the Send button while the reply streams; pressing it shows a short "Stopped." line. Force Stop is a red banner that appears only if Stop has not taken effect after about fifteen seconds. It only stops the app waiting, so the provider may keep billing for a while. Moving to another chat or agent does not stop a reply in progress.
- The **model picker** is the chip in the row of controls above the message box, displaying the current model name. Clicking it opens a curated short list of models grouped by provider. It lists models from the providers you saved a key for (plus a model server on your own computer if you run one), and each model shows its provider next to its name. Your default for new chats is first set from the provider key you saved first.
- The short list is intentional. Most providers ship dozens of models and the differences rarely matter for most work. The list shows what the Clawless Computer team recommends.
- If the model you want is not on the short list, type the **provider-prefixed name** into the picker (for a provider the picker offers). The pattern is the provider slug, a slash, and the model name, as in:

```text
openai/gpt-5.4-mini
```

- You can **switch models mid-conversation**. The new model picks up the full conversation history and continues where the previous one left off. There is no per-conversation model lock. This is load-bearing: it lets you use a big model for the hard first question and switch to a cheaper one for ten small follow-ups, so each follow-up costs less without restarting the thread.
- A model you pick inside a chat applies to **that chat only**. New chats start with your default, which you change in Settings, API Keys, under "Default model for new chats". Agents that have no model of their own use it too.
- **Costs follow the current model**, message by message. Switching does not retroactively change anything; it changes the meter going forward.
- Each **agent** on the left rail keeps its own conversation thread and its own preferred model. Clicking between agents swaps both. The picker updating when you switch agents is intentional, not a glitch.
- The model name in the chat header shows the **current** model you have selected. If you switch models mid-conversation, the header reflects the model you have selected.
- The **Usage panel**, on the navigation rail at the far left, breaks down cost by provider, model, and conversation. Opening it after your first few conversations is the fastest way to build intuition for what each model costs you in practice.
- **Slash commands** (typing a forward slash at the start of the input) are a power-user shortcut, including one to switch models without leaving the keyboard. Safe to ignore for the first hour.

## What changes for you

Before this lesson, choosing a model probably felt like a permanent commitment per conversation, the way "which app do I open" works in most software. Now you know the picker is a live dial, not a setup choice, and that the cost-and-capability tradeoff is something you can adjust message by message. The most useful habit forming here is **starting hard, then dropping down**: open the conversation on a big capable model so the first reply is strong, then switch to something smaller and cheaper once the work is mostly follow-ups. Every other Clawless Computer feature (Skills, Tools, Memory, agent customization) sits on top of this one capability, so the time spent practicing it in the hands-on pays back across everything else.
