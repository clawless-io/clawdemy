## The three screen areas

| Area | Where | What it holds |
| --- | --- | --- |
| Agent rail | Left edge, vertical strip | One avatar per agent. Assistant is the friendly default. Click to switch agents. |
| Chat | Center | Four parts: header (agent avatar, conversation title, current model), message area, the row of controls, the message box. |
| Navigation rail | Far left, narrow icon strip | Panels: Tools, Skills, Memory, Channels, Cron, Logs, Usage, Settings. |

The row of controls above the message box holds, in order, New conversation, the model picker, Skills, Tools, Commands and Feedback.

## The model picker at a glance

| Property | Value |
| --- | --- |
| Location | Chip showing the current model's name, in the row of controls above the message box |
| Display | Current model name |
| Contents | Curated short list, grouped by provider, from the providers you saved a key for (plus a model server on your own computer if one is running). Each model shows its provider next to its name. |
| Default for new chats | First set from the provider key you saved first. Change it in Settings, API Keys, under "Default model for new chats". |
| Off-list models | Type provider-prefixed name directly into the picker (works for a provider the picker offers) |

## The off-list pattern

```text
provider_slug/model_name
```

Worked example:

```text
openai/gpt-5.4-mini
```

Type the pattern into the picker and [Clawless Computer](https://clawless.ai) uses that model even when it is not on the visible short list. Use this only when you have a specific reason; the short-list defaults handle almost everything.

## Sending a message: what you press

| You see | You do | What it means |
| --- | --- | --- |
| Empty input | Click into it, type, press Enter | Sends the message. |
| Status line below your message | Read it | Activity indicator: thinking, reading a file, searching the web, calling a tool. |
| Reply streaming word by word | Read along | Streamed output. No need to wait for the whole reply. |
| Square icon where Send used to be | Click it | Stop. Halts the stream; the chat shows "Stopped." |
| Red banner with Force Stop | Use as last resort | Stop did not take effect after about fifteen seconds. Force Stop only stops the app waiting; the provider may keep billing for a while. |
| Code block in reply | Click Copy in the corner | Lifts the block to clipboard. |

## Switching models mid-conversation

| Rule | Detail |
| --- | --- |
| No per-conversation lock | Switch anytime. The new model sees the full conversation history. |
| Cost meter follows current model | Only the message you are about to send is billed at the new model's rate. Past messages stay billed at their original model. |
| Common pattern: start big, then small | Use a capable model for the hard first question, switch to cheaper for follow-ups. Each follow-up costs less, without restarting. |
| Reverse also works | Start small for an easy task, switch up when it gets harder. |
| A chat's pick stays in that chat | Picking a model inside a chat changes only that chat, not the model new chats start with. |

## Per-agent behavior

| What you click | What changes |
| --- | --- |
| A different agent on the left rail | Conversation swaps (each agent has its own thread). Model picker updates to that agent's preferred model. Neither thread is lost. |
| Picker on the current agent | Model changes for this conversation only. To change an agent's preferred model for good, edit the agent (see the Agents and Overview chapter of the help docs). The default for new chats lives in Settings, API Keys. |

## The header label

The model name in the conversation header shows the **current** model you have selected. If you switch models mid-conversation, the header reflects the model you have selected.

## Four first-day surprises (so they do not surprise you)

| Surprise | Why it happens |
| --- | --- |
| First message of a session feels slow | Engine warmup plus possible provider cold start. Subsequent messages are faster. |
| Status line appears below your message | That is the activity indicator. Tells you what the agent is doing. Not a problem. |
| Switching agents loads a different conversation | Each agent has its own thread, by design. Stay in one agent to continue the same topic. |
| Picker shows different defaults across agents | Each agent has its own preferred model. Picker is following the agent. |

## Worth opening once

The **Usage panel** in the navigation rail, after your first few conversations, breaks down cost by provider, model, and conversation. Reading the real numbers is more durable than guessing what each model costs you.

## Pitfalls to dodge

- Treating the model choice as a permanent setup decision (it is a live dial)
- Re-pasting context after switching models (the new model already has it)
- Starting every conversation on the biggest model (cheap models handle a lot of follow-up work fine)
- Typing slash commands by accident on the first day (safe to ignore for now; the Chat and Models chapter of the help docs lists them)
