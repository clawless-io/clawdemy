## Self-check

Six quick questions. Answer each in your head (or out loud) before opening the collapsible. Active retrieval beats rereading by a wide margin.

**1. Name the three screen areas of [Clawless Computer](https://clawless.ai) and what each one is for.**

<details>
<summary>Show answer</summary>

Agent rail (left, vertical strip of avatars, one per agent), chat (middle, where the conversation happens), navigation rail (far left, opens panels for Tools, Skills, Memory, Channels, Cron, Logs, Usage, Settings). The chat itself has four parts: header, message area, input, and the dock row below the input, which holds frequently used controls including the model picker.

</details>

**2. Where exactly is the model picker, and what does clicking it show?**

<details>
<summary>Show answer</summary>

It is the chip showing the current model's name, next to the message box. Clicking it opens a short, curated list of models grouped by provider. It lists models from the providers you saved a key for (plus a model server on your own computer if one is running), and each model shows its provider next to its name.

</details>

**3. You ask a hard question, get a careful answer from a big model, then have five small follow-ups. What is the cost-saving move, and what will the agent remember?**

<details>
<summary>Show answer</summary>

Switch to a smaller, cheaper model from the model picker before sending the follow-ups. The new model picks up the full conversation history and continues where the previous one left off, so nothing is lost. Costs follow the model you are using at the moment you send each message, so the meter drops immediately for the follow-ups.

</details>

**4. The model you want is not on the curated short list. How do you use it anyway?**

<details>
<summary>Show answer</summary>

Type the provider-prefixed name straight into the picker. The pattern is the provider slug, a slash, and the model name, as in:

```text
openai/gpt-5.4-mini
```

Clawless Computer then uses that model even if it is not on the visible short list, as long as you have a key for that provider.

</details>

**5. You click between two different agents on the left rail. What happens to (a) the conversation, (b) the model selection?**

<details>
<summary>Show answer</summary>

Each agent keeps its own conversation history, so clicking between them swaps you between two parallel threads. The model picker updates to that agent's preferred model. You do not lose your place in either thread, and the picker change is intentional (each agent has its own default), not a glitch.

</details>

**6. Can you switch models mid-conversation, what does the new model see when it takes over, and does your pick change your other chats?**

<details>
<summary>Show answer</summary>

Yes. There is no per-conversation model lock. The new model picks up the full conversation history and continues where the previous one left off, so you do not have to re-paste context. The cost meter follows the model you are using at the moment you send each message, so the savings (or extra cost) take effect immediately and only forward, never retroactively. The pick applies to that chat only; new chats start with the default you set in Settings, API Keys, under "Default model for new chats".

</details>

## Try it yourself: the 20-minute hands-on

The body lesson gave you the map. This is where you walk the ground. Three real messages, one mid-conversation model switch, one off-list model. Twenty minutes start to finish.

**Side effects:** real API calls against the provider whose key you saved during onboarding. Each message uses a small amount of credit with that provider; the Usage panel shows the real number at the end.

**Steps:**

1. **Open Clawless Computer.** Confirm you are on the Assistant agent (the friendly default on the left rail). If you are elsewhere, click Assistant.

2. **Find the model picker.** Look next to the message box for the chip showing the current model name. You should be able to point at it without searching.

3. **Send your first message.** Type one of the following (or your own real question), then press Enter:
   - "Help me write a short status update to my team about a project that is on track but had two small blockers this week. Keep it three sentences. Confident tone."
   - "I have a coffee chat next week with someone whose career I want to learn from. Draft five open questions I could ask, ranging from light to substantive."

   Watch the activity indicator below your message. Read the reply as it streams in.

4. **Send a follow-up in the same conversation.** Without changing the model, ask the agent to revise the reply in some way ("make the tone a bit warmer", "drop the second bullet", "add a sentence about timing"). Confirm that the agent remembers the original context without you re-pasting it.

5. **Switch to a smaller model.** Open the model picker. Pick a smaller model from the short list (usually one with a name like mini, nano, flash or haiku). The picker closes and the chip now shows the new model name. Send one more follow-up in the same conversation. Watch the activity indicator. Notice that the conversation continues without missing a beat, and the new model still has access to everything you and the previous model said.

6. **Try one off-list model.** Open the model picker again. Type a provider-prefixed name directly into it, using the provider you saved a key for. The help docs give this example, which works if you saved an OpenAI key:

   ```text
   openai/gpt-5.4-mini
   ```

   (If your key is from a different provider, use that provider's slug and one of its model names. The format is always provider slug, slash, model name. A name for a provider you have no key for does not work; the chat tells you to add a key or pick another model.) Send one short message and confirm the model name in the header updates to the off-list model after the reply lands.

7. **Open the Usage panel.** Click the Usage icon in the navigation rail on the far left. Look at the Models tab to see cost by the models you used, and the Sessions tab to find this conversation.

**Expected outcome:** you finish with one conversation that has three to five messages across at least two different models, a feel for how the picker works in your hands, and a real number in the Usage panel for what those messages actually cost.

If something went sideways: the most common first-day surprises are listed at the end of the lesson body. Re-read those before assuming Clawless Computer is broken.

## Flashcards

Ten cards. Review once a day for a week, then on the intervals your spaced-repetition tool suggests.

<FlashcardSet>

<Flashcard question="What are the three screen areas of Clawless Computer?">

The agent rail (left, avatars), the chat (middle, the conversation), and the navigation rail (far left, panels). The chat has four parts: header, message area, input, and the dock row below the input.

</Flashcard>

<Flashcard question="Where is the model picker?">

The chip next to the message box. It shows the current model name.

</Flashcard>

<Flashcard question="What is the cost rule when you switch models mid-conversation?">

Costs follow the model you are using at the moment you send each message. Switching does not retroactively change any past cost; it only changes the meter going forward.

</Flashcard>

<Flashcard question="Why is the model picker's list short and not exhaustive?">

It is a curated short list of recommended models, grouped by provider. Most providers ship dozens of models and most of the differences do not matter for most work, so you do not have to choose between thirty options on day one.

</Flashcard>

<Flashcard question="How do you use a model that is not on the short list?">

Type the provider-prefixed name into the picker: provider slug, slash, model name, for a provider you have a key for. For example:

```text
openai/gpt-5.4-mini
```

</Flashcard>

<Flashcard question="What happens to the conversation when you switch models mid-thread?">

The new model picks up where the previous one left off. It sees the entire conversation history. There is no per-conversation model lock.

</Flashcard>

<Flashcard question="What does the activity indicator tell you?">

What the agent is doing in real time: thinking, reading a file, searching the web, calling a tool. If you ever wonder whether the agent is stuck, the activity indicator is your answer.

</Flashcard>

<Flashcard question="What is the difference between Stop and Force Stop?">

Stop is the regular button (replaces the Send button while the agent is streaming); the chat shows "Stopped." Force Stop is a red banner that appears only if Stop has not taken effect after about fifteen seconds. It only stops the app waiting, so the provider may keep billing for a while. Use it as a last resort.

</Flashcard>

<Flashcard question="What changes when you click a different agent on the left rail?">

Two things at once: the chat swaps to that agent's separate conversation history, and the model picker updates to that agent's preferred model. You do not lose your place in either agent's thread.

</Flashcard>

<Flashcard question="What does the model name in the chat header show, especially after you switch models mid-conversation?">

The current model you have selected. If you switch models mid-conversation, the header reflects the model you have selected, not whichever model produced the previous reply.

</Flashcard>

</FlashcardSet>
