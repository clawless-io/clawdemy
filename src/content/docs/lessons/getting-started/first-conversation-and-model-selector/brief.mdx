## What you'll learn

This is the first hands-on lesson of the Getting Started track and the one the rest of the track stands on. Its practice is written for [Clawless Computer](https://clawless.ai), the free desktop home for OpenClaw that we build alongside Clawdemy. You send your first message and learn the model picker, the chip above the message box that lets you choose which AI model handles each message. You will see how to switch models in the middle of a conversation without losing your place, why there is no per-conversation lock, and how to reach a model that is not on the curated short list. By the end you will have a working mental map of the three screen areas (agent rail on the left, the chat in the middle, and the navigation rail at the far left), the four parts of the chat (header, message area, the row of controls, the message box), what that row of controls holds (New conversation, connection status, the model picker, Skills, Tools, Create (for images), Commands, then today's cost and Feedback at the right), and a feel for how the cost meter, the header label, the default for new chats, and per-agent preferences actually behave when you click around.

## Before you start

**Prerequisites:** lesson 1 (*AI won't replace you. But it will expose you.*), where you picked one recurring task and split it into mechanical and judgment parts. You will use that task as the conversation starter for the practice. You also need Clawless Computer installed and its onboarding finished, with at least one provider API key saved. If onboarding is not done, finish it first and come back; the lesson assumes the chat surface is in front of you.

## By the end, you'll be able to

- Identify the three screen areas of Clawless Computer (agent rail, chat, navigation rail) and the four parts of the chat (header, message area, the row of controls, the message box)
- Send a first message and use the activity indicator and Stop button to control the response stream
- Switch models mid-conversation using the model picker, and explain why there is no per-conversation model lock
- Use the provider-prefixed pattern (the provider's short name, a slash, the model name) to select a model that is not on the curated short list
- Predict how the cost meter, the chat header label, the default for new chats, and per-agent preferences behave when you switch models or switch agents

## Time and difficulty

- **Read time:** about 11 minutes
- **Practice time:** about 20 minutes (a hands-on with four short messages, one mid-conversation model switch, and one off-list model, ending with the Usage panel for the real cost numbers)
- **Difficulty:** intro
