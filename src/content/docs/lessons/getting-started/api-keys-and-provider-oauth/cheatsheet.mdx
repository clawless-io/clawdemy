## The mental model

An **API key** is a string of characters the AI provider gives you so their system can recognize your requests. Two roles in one: **authentication** (you are allowed to use it) and **accounting** (who to bill). You paste it into [Clawless Computer](https://clawless.ai) once and Clawless Computer does the rest.

## BYOK in one line

**BYOK = Bring Your Own Key.** Your key, your provider account, the provider bills you directly at published rates. **Clawless Computer takes no markup.** No combined bill: Clawless Computer itself is free and open source, with no trial and no account; AI usage is billed by your provider.

## Where the key lives

| State | Where |
| --- | --- |
| You typed it once | The API Keys step in onboarding, or Settings, API Keys |
| After Save | Kept by the OpenClaw engine in its own database inside your data folder, on your computer |
| Who can read it | Only your user account on the computer, and tools the assistant runs as your account (not encrypted there; turn on FileVault or BitLocker for stronger protection) |
| Never shown again | Clawless Computer never displays a saved key |
| Not synced | Each install keeps its own data; a moved or backed-up data folder carries your keys |
| Leaked key | Revoke it on the provider's site; removing it in the app alone is not enough, because copies can stay in the data folder and in backups |

## The Settings page (where you manage keys)

1. **Settings.** Gear icon at the bottom of the navigation rail on the far left.
2. **API Keys section.** Sticky sidebar on the left of the Settings page.
3. **Row per provider,** grouped into categories: Recommended (open by default), Cloud Providers (Anthropic, OpenAI, Google, Groq, Mistral, and many more), Gateways (such as OpenRouter), Self-hosted, and others.
4. **Per-row controls.** Get API Key link (jumps to the provider's key page), paste the key, Save, status (green check, or a red message).
5. **Remove a key.** Trash icon on the row. The key is deleted (copies can stay in the data folder and backups); the provider is unavailable until you add a key back. If it held your default model, a new default is picked, possibly priced differently.
6. **Default model for new chats.** Button on the same page; pick a model, press Make default.

## When a key stops working

| Cause | Fix |
| --- | --- |
| Typo on paste | Re-copy the key from the provider's dashboard; paste again; Save |
| Revoked or rotated | Generate a new key on the provider's dashboard; paste the new one |
| Out of credits | Top up on the provider's site; Clawless Computer resumes on the next successful call |

Check the provider's row in Settings, API Keys, which shows each key's state; a message that does not go through is the other clue. Fix the cause, then save the key again in Settings, API Keys: a green check means it works, a red message means it does not.

| --- | --- |
| Google (Gemini) | Generous free tier; gentle entry point if "no spending yet" matters |
| Groq | Generous free tier; same |

| OpenAI | Pay-as-you-go on API; small one-time signup credit sometimes included; no ongoing free tier on API path |

The provider's terms are the provider's terms; Clawless Computer does not change them.

## Adding a second provider (the 5-step path)

1. Settings, gear icon at the bottom of the navigation rail.
2. Click the API Keys section.
3. Find the provider's row, click it.
4. Click the Get API Key link, generate a key on the provider's site, copy it.
5. Paste it into the Clawless Computer input box, click Save. Green check on the row when verified. The new provider's models now appear in the model picker, each with its provider named next to it.

**GitHub Copilot** is added with a GitHub token instead of a regular API key. CostGuard counts it at the provider's list price for the same model, so it can reach your cap even if your Copilot plan bills you differently.

Practical: do not connect more providers than you actually use. Two or three is plenty for most people.

## Default model for new chats

Clawless Computer first sets it from the **provider you set up first**. New chats use it, and so do agents with no model of their own. Change it in **Settings, API Keys**, with the Default model for new chats button: pick a model, press Make default. A model picked inside a chat changes only that chat; existing chats keep theirs.

## Pitfalls to dodge

- Assuming there is one combined Clawless Computer-plus-AI bill (there is not; the AI bill is between you and the provider)
- Looking for a provider in the model picker before adding its key (the picker lists only providers that hold a key)
- Treating the green check as a quality signal (it only means authenticated and reachable; runtime conditions like rate limits and empty credits are not the same as "key works")
- Connecting six providers because the list looks tempting (each is one more thing to keep current; two or three is plenty)
- Expecting keys to sync to a second computer (they do not; each install keeps its own data)
- Leaving a data-folder backup somewhere others can reach (it holds your API keys)

## Worth opening once

The **API Keys page in Settings**, weekly for the first month. The fastest way to learn whether a "this is broken" feeling is actually a broken key (save it again and look for the green check), an empty wallet, or something else.
