You finished lesson 2 with one conversation under your belt. You typed something, an AI replied, you switched the model once just to see what it felt like.

This lesson is about the invisible piece that made all of that possible.

Every message you sent in lesson 2 went to an AI provider, somewhere on the internet, and came back to you. The provider needed two things from you before it would answer. It needed to know you are allowed to use it (authentication). And it needed to know who to bill (accounting). Both of those answers live inside one small piece of text called an API key.

This lesson is about API keys. Where they come from, where they live, which model your new chats start with, and what happens if one breaks.

About ten minutes to read, give or take.

## What an API key actually is

An API key is a string of characters the provider gives you so their system can recognize your requests. It looks something like this:

```text
sk-ant-1a2b3c4d5e6f...
```

You paste it into [Clawless Computer](https://clawless.ai) once. Clawless Computer keeps it on your computer and uses it on every message you send. The app never shows a saved key on screen again.

The important mental model is that the key represents **your account with the provider**, not your account with Clawless Computer. There is no "Clawless Computer account" that holds your usage; you pay the AI provider directly for every message, and Clawless Computer just sits on your desk making the conversation flow nicely. Your messages go from your computer straight to the provider, not through any Clawless Computer servers.

This is what BYOK means. It stands for "bring your own key," and it is how Clawless Computer works. You bring your account with Anthropic (or OpenAI, or Google, or Groq, or any other supported provider). They bill you. Clawless Computer does not get in the middle.

There are two reasons this matters in practice. First, whatever the provider offers you, you keep. Some providers run a generous free tier (Google's Gemini free tier, Groq); others (Anthropic, OpenAI) are pay-as-you-go from the start, sometimes with a small one-time signup credit but no ongoing free allowance. Either way, the provider's terms are the provider's terms; Clawless Computer does not change them. Second, when you do pay, you pay the provider their published rates, not a Clawless Computer markup. There is no markup.

## Where your keys live, after onboarding

The onboarding wizard from your first launch is where you added your first key. After that, the place to manage keys is in Settings.

Open Settings from the gear icon at the bottom of the navigation rail on the far left. The page opens, and on the left there is a sticky list of categories. Click the API Keys section.

You see a row for every supported provider, grouped into categories you can open and close: Recommended, Cloud Providers, Gateways, Self-hosted, and a few more. Recommended is open by default. Cloud Providers is the long list, with Anthropic, OpenAI, Google, Groq, Mistral, and many others. Gateways, such as OpenRouter, let one key reach many model providers. Each row shows whether you have a key set up and whether the key is currently working.

To add a key for a provider you have not connected yet, click that provider's row. Each row has a Get API Key link that takes you straight to the right page on that provider's site. You go to the provider's page, generate a key, copy it, paste it into Clawless Computer, and click Save. Clawless Computer verifies the key in the background; a green check means it works, and a red message means it does not.

To remove a key, click the small trash icon on its row. Clawless Computer deletes the key, and that provider is no longer available until you add a key back. An agent whose preferred model was from that provider goes back to your default model. A chat that used that provider also moves to your default model, and it shows a line asking you to pick a model for that chat. If your default model for new chats was from that provider, Clawless Computer picks a new default from a provider you still have a key for, and that new model may be priced differently.

You can have keys for several providers at once. Most people do not need more than one to start. Adding a second is useful when you want to compare models across providers, or when one provider is having a slow afternoon and you want the option to fall back to another.

The default model rule is worth remembering. Clawless Computer first sets your default model from the provider you set up first. New chats start with that default, and so do agents that have no model of their own. An agent that has its own preferred model keeps it; to change that, edit the agent. If you later add a second provider and prefer it, open Settings, API Keys, and click the Default model for new chats button. Pick a model from the list and press Make default. A model you pick inside a chat changes only that chat, and your existing chats keep theirs.

## If you already pay for ChatGPT

Many people meet AI through a ChatGPT subscription, so a fair question is whether you can sign in with that account instead of pasting a key.

Not in this version. Signing in with a ChatGPT account comes back in a later update. Until then, OpenAI works with an API key. You add it the same way as any other provider's key: click the OpenAI row in Settings, API Keys, follow the Get API Key link, paste the key, and click Save.

## When a key stops working

Sometimes a key you saved this morning stops working this afternoon. There are three common reasons, and the fix is different for each.

**Typo on paste.** This is the most common one. A stray space at the end, or a key cut short by the copy, is enough to make it fail. Re-copy the key from the provider's dashboard, paste again, and click Save. If you are not sure whether it was a typo, you can usually tell because the failure happens immediately on save, not later.

**Revoked or rotated.** You (or your team) may have rotated keys on the provider side, or the provider may have rotated a leaked key on your behalf. The fix is to generate a new key on the provider's dashboard and paste the new one into Clawless Computer. The old one is simply gone.

**Out of credits.** Most providers (Anthropic, OpenAI, and others on the pay-as-you-go model) require a positive balance to make calls; one-time signup credit, if there is one, eventually runs out. If your balance hits zero, every call fails with a credit-related error. The fix is to top up on the provider's site. Clawless Computer resumes sending the moment the next call succeeds.

Each provider row in Settings, API Keys shows a small health indicator, so you can check a provider before you send anything. If a message does not go through, that row is the first place to look. Fix the underlying cause and save the key again. On save, a green check means the key works, and a red message means it still does not.

## Adding more than one provider

Most lessons later in this track assume you have at least one provider connected. Some practice exercises are easier if you have a second, because you can compare answers across providers without changing your subscription.

To add a second provider:

1. Open Settings from the gear icon at the bottom of the navigation rail.
2. Click the API Keys section in the sidebar on the left of the page.
3. Find the provider you want to add. Click the row.
4. Click the Get API Key link that opens; that takes you to the provider's key-creation page.
5. Generate a key on the provider's site, copy it, paste it into the Clawless Computer input box, click Save.

The row shows a green check when Clawless Computer verifies the key. The model picker, the chip just above the message box, lists models only from providers that hold a key, so the new provider's models now appear there. Each model shows its provider next to its name, because the same model can be offered by more than one provider.

One more provider on the list connects a little differently: GitHub Copilot, which you add with a GitHub token instead of a regular API key. If you use it, know that CostGuard, the spending cap you meet in a later lesson, counts Copilot use at the provider's list price for the same model. So it can reach your cap even though your Copilot plan may bill you differently.

You can repeat this for as many providers as you like. Practical advice: do not connect more providers than you actually use. Each connection is one more place to keep keys current and one more potential failure point. Two or three is plenty for most people.

## A few small things you will notice

The Get API Key link on each provider row takes you to the same page you would land on if you had gone hunting for it yourself. It is just a convenience, not a special back channel.

Your keys stay on your computer. OpenClaw, the open-source engine that Clawless Computer runs on, keeps them in its own database inside your Clawless Computer data folder. Only your user account on the computer can read them, and Clawless Computer never shows a saved key on screen. Tools the assistant runs on your computer run as your account too, so they could read the same files. The keys are not encrypted inside that folder, so for stronger protection turn on your computer's disk encryption (FileVault on a Mac, BitLocker on Windows). If you delete the data folder, the keys go with it. Removing a key in Settings deletes it, but copies can stay behind inside the data folder and in your backups. So if you think a key may have leaked, removing it from Clawless Computer alone is not enough; revoke it on the provider's site.

Keys do not sync between computers. Each install keeps its own data on that machine. If you move your data folder to another Mac, your keys come with it, which also means any backup copy of that folder holds your keys. Keep backups somewhere only you can reach.

## Common first-day surprises

Five things people often notice on the first day around API keys.

1. **You do not have to pay Clawless Computer for AI usage. You pay the provider.** Clawless Computer itself is free and open source, with no trial and no account; the AI conversations bill through whichever provider's key you have set up. This catches people who assume there is one combined bill.

2. **Free tiers exist, but vary widely.** Google's Gemini free tier and Groq run a generous free allowance and are good places to experiment without spending. Anthropic and OpenAI are pay-as-you-go on the API side; a small one-time signup credit is sometimes included, but there is no ongoing free tier. If "I want to try without paying anything" is your first goal, Google or Groq is the gentler entry point.

3. **The model picker only shows providers you have a key for.** If a provider is missing from the picker, check Settings, API Keys first. With no key at all, the picker says "Add a model key in Settings" and links there.

4. **Removing a key does not delete your conversations.** Keys are about authentication going forward. Your past conversations stay in your local conversation history regardless of whether the key that produced them is still saved. A chat that used that provider moves to your default model and asks you to pick a model for it.

5. **The "green check" is not a quality signal.** A green check on a provider row only means the key authenticates and the account is reachable. It does not mean the model is fast today, or that the provider has no rate limits, or that your free credits have not run out. Those are runtime conditions you discover as you go.

## What you should remember

- **An API key is your account with the provider, not your account with Clawless Computer.** BYOK means you bring your own key, the provider bills you directly, and Clawless Computer takes no markup. The key stays in your data folder on your computer, and the app never shows it again.
- **Keys are managed in Settings, in the API Keys section.** That is where you add a new provider, see which keys are working, and remove a key when you stop using a provider.
- **New chats start with your default model.** Change it in Settings, API Keys, with the Default model for new chats button. A model picked inside a chat changes only that chat.
- **OpenAI works with an API key.** Signing in with a ChatGPT account comes back in a later update.
- **When a key stops working, check its row in Settings, API Keys.** Each row shows the key's state; a message that does not go through is the other clue. Typo, rotated key, and out-of-credits are the three common causes. Fix the underlying cause and save the key again; a green check on save means it works.

In the practice that goes with this lesson, you confirm your existing provider is connected and (optionally) add a second one. About fifteen minutes if you have a key handy from another provider, longer if you have to sign up. Either path lands you ready for the rest of the track.
