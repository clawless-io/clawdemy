## Source material

The lesson is anchored on five chapters from the [Clawless Computer](https://clawless.ai) knowledge base, the single source of truth for Clawless Computer behavior. Inside the app, open Settings, About, and click Documentation to read these chapters on GitHub. The product itself lives at [clawless.ai](https://clawless.ai).

```
Clawless Computer KB chapters cited:

PRIMARY (the onboarding wizard and where the first key is added)
• Clawless Computer Knowledge Base, "Getting Started with Clawless Computer" chapter
  Step 3, API Keys: the Get API Key link, paste and Save, the green
  check, the typo and trailing-whitespace fix, and the line that
  signing in with a ChatGPT account comes back in a later update
  while OpenAI works with an API key.

PRIMARY (managing keys and the default model after onboarding)
• Clawless Computer Knowledge Base, "Settings Reference" chapter
  The API Keys section (provider categories, Add key, Get API Key
  link, Remove key) and "Default model for new chats" (Make default,
  a chat's own pick changes only that chat, the first default comes
  from the provider set up first).

SUPPORTING (how saved keys are stored)
• Clawless Computer Knowledge Base, "What is Under the Hood" chapter
  API keys are kept by the OpenClaw engine in its local database
  inside the data folder, not encrypted, readable only by your user
  account; Clawless Computer never displays a saved key; removing a
  key deletes it but copies can linger in the file and in backups;
  tools the assistant runs as your account could read it; disk
  encryption and revoking a leaked key with the provider.

SUPPORTING (the model picker and removing a key)
• Clawless Computer Knowledge Base, "Chat and Models" chapter
  The picker lists only providers that hold a key and names the
  provider on every model; what happens to chats, agents and
  the default model (possibly priced differently) when a key is removed.

SUPPORTING (GitHub Copilot and the spending cap)
• Clawless Computer Knowledge Base, "CostGuard" chapter
  GitHub Copilot, added with a GitHub token, counts at the
  provider's list price for the same model.

Also consulted: "Your data and backups" (moving the data folder
carries your API keys; keep backups somewhere only you can reach).

Source: Clawless Computer documentation, RBJ Global LLC. This lesson follows the documentation's framing on key handling
and the default model, expressed in original prose for a Clawdemy
reader adding their first provider.
```

## Going deeper inside Clawless Computer

Two follow-on KB chapters once the basics are in place.

- **Clawless Computer Knowledge Base, "Usage and Cost" chapter.** The Usage dashboard in detail. Useful when you have a few weeks of conversations behind you and want to know where the money actually went.

- **Clawless Computer Knowledge Base, "Agents and Overview" chapter.** Each agent has its own preferred model, which you change by editing the agent. Worth a read after this lesson if you have connected multiple providers and want to change which agent uses which provider.

## Going deeper outside Clawless Computer

One outside source for readers who want context on what an API key actually is.

- **["What is an API key?"](https://www.cloudflare.com/learning/security/api/what-is-an-api-key/)** at Cloudflare Learning. The cleanest one-page explanation of API keys in general (not specific to AI), aimed at non-developers. Covers what a key is, why it is sensitive, and the rotation/revocation lifecycle. Useful background if "API key" felt like wizardry when you read the lesson.
