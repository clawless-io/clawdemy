## The short version

An API key is a string of characters the AI provider gives you so their system can recognize your requests, both for authentication and for billing. You paste it into [Clawless Computer](https://clawless.ai) once, it is kept in your data folder on your computer, and Clawless Computer uses it on every message. This is the BYOK model: bring your own key, the provider bills you directly, Clawless Computer takes no markup. OpenAI works with an API key like every other provider; signing in with a ChatGPT account comes back in a later update. Keys are managed in Settings, API Keys after onboarding, and so is the default model for new chats. When a key stops working, check the provider's row in Settings, API Keys, which shows each key's state; a message that does not go through is the other clue. The cause is one of three things: typo on paste, revoked or rotated, or out of credits. The fix is straightforward in each case.

## Core ideas

- An **API key** is a string the provider issues so their system can recognize your requests. It serves two roles in one: authentication (you are allowed to use it) and accounting (who to bill).
- A typical key has a short prefix that identifies the provider followed by a long string of characters, in this shape (Anthropic example, other providers vary):

```text
sk-ant-1a2b3c4d5e6f...
```

You paste it into Clawless Computer once during onboarding or in Settings.
- **The key never appears on screen again** once saved. OpenClaw, the open-source engine Clawless Computer runs on, keeps it in its own database inside your data folder, readable only by your user account. Tools the assistant runs on your computer run as your account too, so they could read the same files. It is not encrypted there, so turning on your computer's disk encryption (FileVault on a Mac, BitLocker on Windows) adds protection. Removing a key deletes it, but copies can stay behind in the data folder and in backups, so if a key may have leaked, revoke it on the provider's site.
- **BYOK** stands for "bring your own key." The key represents your account with the provider, not with Clawless Computer. The provider bills you directly at the provider's published rates; **Clawless Computer takes no markup**.
- **There is no combined bill.** Clawless Computer itself is free and open source, with no trial and no account; the AI conversations bill through whichever provider's key you have set up. This catches people on the first day who assume one bill covers both.
- Keys are managed in **Settings, API Keys**. The page lists every supported provider as a row, grouped into categories such as Recommended, Cloud Providers (Anthropic, OpenAI, Google, Groq, Mistral, and many more) and Gateways (such as OpenRouter). Each row shows whether you have a key and whether it currently works.
- A **green check** on a provider row means the key authenticates and the account is reachable. It does not mean the model is fast today or that you have credits left; those are runtime conditions.
- The **default model for new chats** is first set from the provider you set up first. New chats use it, and so do agents with no model of their own. Change it in Settings, API Keys, with the Default model for new chats button, then Make default. A model picked inside a chat changes only that chat.
- The **model picker** lists models only from providers that hold a key, and shows the provider next to every model name.
- **OpenAI works with an API key.** Signing in with a ChatGPT account comes back in a later update.
- **When a key stops working**, check the provider's row in Settings, API Keys, which shows each key's state; a message that does not go through is the other clue. Three common causes: typo on paste, revoked or rotated key, out of credits on a pay-as-you-go account. Fix the cause and save the key again in Settings, API Keys: a green check means it works, a red message means it does not.
- **Removing a key does not delete your past conversations.** Keys are about authentication going forward. If the removed key's provider held your default model, a new default is picked from a provider you still have a key for, and it may be priced differently.
- **Free tiers vary widely.** Google's Gemini free tier and Groq run a generous free allowance, good places to experiment without spending. Anthropic and OpenAI are pay-as-you-go on the API side from the start.
- **Multiple providers are supported but not required.** Two or three connections is plenty for most people. More connections means more keys to keep current and more potential failure points.
- **GitHub Copilot** is added with a GitHub token rather than a regular API key. CostGuard counts its use at the provider's list price for the same model, so it can reach your cap even though your Copilot plan may bill you differently.
- **Keys do not sync across machines.** Each install keeps its own data on that computer. If you move your data folder to another Mac, your keys come with it, so keep any backup copy somewhere only you can reach.

## What changes for you

Before this lesson, the path from "I want to use AI" to "AI is actually responding to me in Clawless Computer" probably involved some hand-waving about how the bill works. Now you have the mental model directly: there is no Clawless Computer account that holds your AI usage, there is your provider account, and Clawless Computer is the place where you bring it together. The most useful new habit is **checking the Settings, API Keys page when something feels off**, before you assume Clawless Computer is broken. Each provider row there shows the key's state, and a message that does not go through is the other clue. Saving the key again tells you whether it works, and the three usual causes (a typo, a revoked key, or empty credits) have three different fixes with different speeds. The lessons that follow on this track all assume you have at least one provider connected and healthy, so leaving this lesson with a healthy provider row (or two) is the working foundation for everything else.
