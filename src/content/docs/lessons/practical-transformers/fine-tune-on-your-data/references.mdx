## Read this next

- **[Hugging Face LLM Course, Chapter 3: Fine-tuning a pretrained model](https://huggingface.co/learn/llm-course/chapter3)**. The chapter this lesson mirrors. It also walks the data-processing section in full and shows the same fine-tune written as a pure PyTorch training loop, which is worth seeing once to know what the Trainer is doing for you.

## Going deeper

A short, durable list. Each link is a specific next step, not a generic pile.

- **[The `transformers` training guide](https://huggingface.co/docs/transformers/training)**. The official docs version of this lesson, with more detail on preparing datasets and the full set of training options.

- **[TrainingArguments API reference](https://huggingface.co/docs/transformers/main_classes/trainer)**. Every knob the configuration object exposes. Skim it once so you know what is available before you need it (learning rate, schedules, logging, checkpointing, mixed precision).

- **[The `evaluate` library](https://huggingface.co/docs/evaluate/)**. The metrics catalog used in `compute_metrics`. Browse it to see which metric is standard for your task before you invent your own.
